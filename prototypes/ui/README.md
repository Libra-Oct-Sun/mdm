# UI 原型

三套静态原型用于比较工作区、标签和左右分栏的视觉方向。它们不是当前应用代码的一部分，
点击 HTML 或 PNG 可直接查看。

| 方案 | 文件 | 视觉方向 | 多文档交互 |
| --- | --- | --- | --- |
| 纸墨 | `a-paper.html` / `a-paper.png` | 米白纸感、宋体正文、玉色与印章红，偏编辑/写作 | 共享标签栏 + 左右分栏，中间分隔条可拖动 |
| 夜航 | `b-night.html` / `b-night.png` | 深墨蓝、黄铜强调、衬线阅读，偏沉浸/夜间 | 左右栏各自拥有标签组，标签可跨栏迁移 |
| 蓝图纸 | `c-blueprint.html` / `c-blueprint.png` | 冷灰蓝、制图网格、信息密度更高，偏工作台 | 文件栏 + 双栏，分隔条带刻度与双击复位暗示 |

共同展示的能力：

- 多个 Markdown 文件同时打开
- 标签左右拖动排序
- 左右分栏与拖动中间分隔条
- 合并单元格、多段落单元格
- 每栏独立滚动、选区和保存状态
