SPECIFICATION / 0.4

一个安静但不失结构的工作区

双栏不是为了同时做两件事，而是为了让两份文档之间的关系变得可见。左边是正在写的，右边是正在对照的。

界面的骨架应该像制图桌：文件、标签、编辑面和状态栏各自有明确的位置。拖动只发生在有结构意义的地方，用户不需要猜。

01　工作区原则 LAYOUT
区域行为
双栏标签可拖动只改变文档位置
分隔条可拖动改变两栏比例

单栏是默认模式。

双栏是显式进入的对照模式，不是把页面硬切成两半。
规则拖动后的布局要能恢复。双击分隔条回到 50 / 50，关闭任一侧时另一侧扩展到全宽。

INTERACTION / DRAFT

拖动与对照

2026-10-20 · 版本 0.4 · 待评审
01拖动标签

标签在栏内左右移动调整顺序。拖到另一栏时，原标签整体迁移，不复制文档。

02拖动分隔条

拖动时只更新布局比例，不触发重新渲染。松开后保存当前工作区状态。

03关闭一栏

另一栏自动占满宽度。未保存文档继续保留，只关闭编辑视图。

状态约定 STATE
01每栏有独立选区、滚动位置和历史记录。
02脏状态跟随文档，不跟随 pane。
03窗口关闭时统一检查所有打开的文档。
