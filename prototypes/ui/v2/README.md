# 简洁 / 高效 UI 原型

这一版围绕“减少装饰、减少寻找、让状态可见”重做三套方向，均保留单编辑面与标签拖动排序。

| 方案 | 文件 | 核心取向 |
| --- | --- | --- |
| 静默工具 | `a-quiet-tool.html` / `a-quiet-tool.png` | 冷白背景、细边框、低对比工具栏；大纲常驻但不抢视线 |
| 专注纸面 | `b-focus-paper.html` / `b-focus-paper.png` | 暖白纸张、隐藏侧栏、窄边目录；高频操作贴近正文 |
| 紧凑工作台 | `c-compact-workbench.html` / `c-compact-workbench.png` | 文件栏 + 大纲 + 右侧文档信息；信息密度最高 |

已落地的 A 方案效果截图：`actual-shell.png`。

三套都展示了：

- 多文件标签与拖动排序提示
- 表格浮动工具条、合并/拆分单元格
- 紧凑工具栏与清晰保存状态
- 桌面端 1600 × 1000 的完整工作区
