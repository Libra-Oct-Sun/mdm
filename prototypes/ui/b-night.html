南山经：从鹊山到招摇

2026.10.20 · 阅读 12 分钟 · 2,184 字

山经的文字有一种奇怪的耐心。它不急着解释异兽，只先告诉你山的方向、树的形状、水的味道。

读到第三遍才发现，真正重要的不是“它是什么”，而是“它如何被看见”。这也是我今天想改编辑器界面的原因。

CHANGELOG / v0.4

文档工作区 API

内部草案 · 仅工程可见

目标是把“打开多个文件”从标签页状态提升为可布局的工作区。每个 pane 拥有独立文档、选区与滚动位置。

ADD增加 `SplitWorkspace`，支持左右两栏拖拽调整宽度。
ADD标签可以拖动排序，拖到另一栏时创建新的 pane。
FIX切换 pane 不再丢失撤销栈与未保存状态。
NOTE同步滚动是可选项，默认关闭，避免误判文档结构。
// workspace state
const workspace = {
  panes: [
    { doc: "山海经札记.md", ratio: 0.52 },
    { doc: "API 变更记录.md", ratio: 0.48 }
  ],
  drag: "resize"
}
交互约定 SPEC
01分隔条左右拖动实时改变宽度，双击回到 50 / 50。
02标签跨栏拖动需要保留原文档，不复制缓冲区。
03关闭 pane 前保留未保存提示。
